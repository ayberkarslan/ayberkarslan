## Profile

I enjoy working close to the hardware.

My main focus is **embedded systems programming with C and C++**,  
designing software that directly interacts with **microcontrollers and sensors**.

I am a **Control and Automation Engineering student** at  
**Yıldız Technical University**, with a strong interest in real-world systems rather than abstract demos.

I use **Linux as my primary development environment** and have experience working with
system-level tools, networking, and server-side components when needed.
